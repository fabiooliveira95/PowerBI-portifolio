
📊 Projeto de Análise de Dados e Dashboard em Power BI
📌 Visão Geral

Este projeto tem como objetivo demonstrar habilidades práticas em Análise de Dados, Python (Pandas) e Power BI, simulando um cenário real de negócio. O foco é transformar dados brutos em insights estratégicos por meio de tratamento, modelagem e visualização de dados.

O projeto foi desenvolvido com fins educacionais e de portfólio, podendo ser adaptado para uso em micro e pequenas empresas.

🧠 Objetivos do Projeto

Realizar limpeza e tratamento de dados com Python (Pandas)

Estruturar dados para análise e visualização

Criar um modelo de dados eficiente

Desenvolver um dashboard interativo no Power BI

Gerar insights de negócio para apoio à tomada de decisão

🗂️ Estrutura dos Dados

Os dados utilizados estão em formato .csv e representam um contexto de pedidos, produtos e departamentos.

📁 Arquivos

M2 - tbDepto.csv → Cadastro de departamentos

M2 - tbProduto.csv → Cadastro de produtos

M2 - tbPedido.csv → Informações gerais dos pedidos

M2 - tbPedidoDet.csv → Detalhamento dos itens dos pedidos

M2 - tbPedidoMetaDados.csv → Metadados adicionais dos pedidos
